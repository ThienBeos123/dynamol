================================================================================
VERIFICATION NOTES
================================================================================

For all 70 test cases:

BASE-10 (Suite A):
- Verify string matches expected decimal representation
- Verify no leading zeros (except "0" itself)
- Verify sign (either present as "-" or absent for positive)
- Verify all characters are decimal digits [0-9]

BASE-N (Suite B):
- Verify string matches expected base-N representation
- Verify all characters are valid for the base:
  * Base 2: [01]
  * Base 8: [0-7]
  * Base 16: [0-9, a-f]
  * Base 64: [0-9, A-Z, a-z, ., /]
- Verify sign handling (only "-" followed by digits)
- Verify no leading zeros (except base representations of 0)

CROSS-CHECK (optional):
- For base-10 values, re-parse output with stobi_strict()
- Verify recovered bigint matches original (or low limbs if truncation)
- Confirms bidirectional correctness (BITOS ↔ STOBI)
