STOBI BASE-64 EDGE TEST CASES - STRICT API ONLY
Focus: Capacity validation and size-aware failures
Input sizes: 64-512 chars (5 cases max at 512 limit)
BigInt capacities: 4-16 limbs (practical range)
================================================================================

NOTES ON BASE-64:
- Charset: 0-9, A-Z, a-z, ., / (64 chars)
- 6 bits per character
- Prefix version: 0, (saves 3 bytes vs 0{64})
- No prefix version: plain base-64 digits
- Sign: +/- prefix allowed
- Base-64 conversion: 6 bits/char → need ceil(input_len * 6 / 64) limbs

LIMB REQUIREMENT CALCULATIONS (for reference):
- 1-10 chars → 1 limb
- 11-21 chars → 2 limbs
- 22-32 chars → 3 limbs
- 33-43 chars → 4 limbs
- 44-54 chars → 5 limbs
- 55-65 chars → 6 limbs
- 66-76 chars → 7 limbs
- 77-87 chars → 8 limbs
- 88-98 chars → 9 limbs
- 99-109 chars → 10 limbs
- 110-120 chars → 11 limbs
- ... pattern continues (roughly 10-11 chars per limb)
- 192 chars → ~12 limbs
- 256 chars → ~16 limbs
